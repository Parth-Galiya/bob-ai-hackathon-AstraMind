## Problem Statement

Port congestion causes billions of dollars in economic impact annually. The 2021 Los Angeles/Long Beach crisis saw 100+ ships waiting offshore for weeks. Today, most port operators still manage vessel arrivals, berth allocation, crane scheduling, and yard capacity using **spreadsheets and manual decisions**.

This creates cascading problems:
- Congestion is detected too late
- Vessels wait offshore for excessive periods
- Berths become overloaded
- Cranes are poorly distributed
- Yard capacity becomes a bottleneck
- Supervisors lack a clear forward-looking operational plan

---

## Solution: PortFlow AI

An intelligent decision-support platform that:

1. **Predicts** congestion hotspots before they become critical
2. **Recommends** alternate routing strategies for at-risk vessels
3. **Optimizes** berth and crane assignments automatically
4. **Monitors** yard capacity with predictive alerts
5. **Generates** an actionable 72-hour operations plan
6. **Explains** every AI/optimization recommendation in plain language
7. **Allows** what-if scenario simulation for proactive planning

## AI/ML Approach

### Congestion Prediction
- **Model**: Gradient Boosting Regressor (`GradientBoostingRegressor`)
- **Training**: Synthetic labeled dataset (2,000 samples) generated from rule-based scoring
- **Features**:
  - Vessel arrival density (12h/24h window)
  - Current berth utilization
  - Container volume incoming
  - Available crane count
  - Crane deficit (required vs available)
  - Yard utilization
  - Vessel priority score
  - Vessel size score
- **Output**: Congestion probability 0–100% per berth + 72h hourly forecast

### Vessel Risk Scoring
Each vessel receives a risk score derived from its assigned berth's congestion prediction, adjusted by vessel size and priority.

---

## Optimization Approach

### Berth Optimizer
- **Algorithm**: Greedy priority-aware assignment
- **Objective**: Minimize waiting time while respecting berth constraints
- **Constraints**: Vessel size compatibility, berth availability, crane count
- **Priority**: Critical > High > Normal > Low vessels

### Crane Optimizer
- Distributes cranes to minimize handling time per vessel
- Accounts for crane capacity (containers/hour) and maintenance status

### Smart Routing
- Identifies vessels at risk (berth congestion > 65%)
- Finds alternate berths with lower risk (>20% improvement threshold)
- Explains each recommendation in natural language

## Dataset

The application uses a **realistic synthetic dataset** generated by the simulation engine:

- **50 vessels** with realistic size/priority distribution
- **8 berths** with compatible size limits
- **24 cranes** distributed across berths
- **5 yard zones** (Alpha–Echo)
- Vessel arrivals follow **wave patterns** (morning rush, day wave, overnight) to create natural congestion

All data is labeled as **DEMO / SIMULATED** throughout the UI.

## Running the Application

### 1. Start Backend

```bash
cd portflow-ai/backend
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Backend will:
- Load demo dataset automatically on startup
- Run congestion prediction
- Run berth/crane optimization
- Generate 72-hour plan
- Expose API at http://localhost:8000

### 2. Start Frontend

```bash
cd portflow-ai/frontend
npm run dev
```

Frontend will be available at: **http://localhost:5173**
